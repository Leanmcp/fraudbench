**Search the knowledge base** for relevant information when appropriate using the provided `KB_search` tool.

> **Important — Oracle KB_search behavior:** The `KB_search` tool uses oracle retrieval. It ignores your query entirely and always returns the same fixed set of documents required for this task. Calling `KB_search` a second time with a different query will return the exact same documents. **One `KB_search` call is sufficient — do not search again.**
